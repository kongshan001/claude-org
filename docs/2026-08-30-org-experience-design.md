# 经验组织系统(org)设计文档

日期:2026-08-30
状态:已批准(用户确认设计 + 追加"人工确认闸门"后进入 MVP 实现)

## 目标

建立一个全局的"经验组织系统":按话题自主识别并沉淀经验,未来任务基于积累的经验动态分配 Agent;大任务可拆给多个 Agent 协作;没有匹配 Agent 时自动拆分事务、创建新角色并持续沉淀。**所有沉淀与角色组织操作都需用户确认后才落盘**(识别自主、写入人工)。

## 作用域与存储

- **全局**:经验池与角色注册表位于 `~/.claude/org/`,所有项目共享
- **纯文件系统 + Markdown**:可读、可 git 备份、零依赖,与现有 skill/agent 文件模式一致

```
~/.claude/org/
├── INDEX.md                  # 总索引:话题清单 + 角色清单(调度入口)
├── topics/
│   └── <话题slug>/
│       ├── README.md         # 话题边界、触发关键词、关联角色
│       ├── experience.md     # 踩坑/结论/决策(追加式,一条一档)
│       └── skills.md         # 话题内验证过的技能/命令/工具
└── agents/
    └── <角色slug>.md         # 实验角色定义(职责/专长/关联话题/经验引用)
```

## 沉淀机制(混合模式 + 人工确认)

- **识别自主**:对话中发现高置信度内容(明确结论、踩坑+修复、验证过的方案、决策+理由)或任务完成后的总结,主动提出建议条目
- **写入确认**:提出"建议条目"(写哪个话题、什么内容)→ 用户确认/修改后才落盘;多条目可合并成一批确认
- **去重**:写入前查同名话题/同结论;归属不准时归入 `general` 兜底话题
- **条目格式**:`日期 | 上下文 | 结论 | 证据/链接`

## 调度与角色生命周期(注册表 + 晋升 + 人工确认)

- **调度**:任务进来 → 按语义匹配 `agents/` 注册表 → 命中则 spawn(Agent 工具,角色定义 + 关联话题 experience 注入 prompt)
- **无匹配角色**:自动拆分事务 → 提交"角色提案"(命名/职责/专长/关联话题)→ 用户批准后创建并 spawn
- **晋升**:提案(角色、理由)→ 用户批准后拷贝为 `~/.claude/agents/<名>.md`(harness 原生类型),注册表保留指针
- **修改/淘汰**(改名/合并):一律先提案后执行
- **多 agent 大任务**:主会话做 Team Lead 拆解,每角色独立任务 + 各自经验回写
- **容错**:spawn 失败回退主会话直接做;角色文件始终可手改

## 封装

机制封装为全局 skill `~/.claude/skills/org/SKILL.md`,定义:何时触发、目录结构、写入规范、调度协议、确认闸门。所有项目可见。

## 验证(最小闭环)

1. **调度已有角色**:派"生成游戏美术资产"任务 → 匹配到美术角色(本次会话经验迁移进池)
2. **自动建角色**:派全新领域任务 → 无匹配 → 角色提案 → 批准后创建
3. **多角色大任务**:派"2D 游戏小 Demo"(美术+动画+打包)→ 拆 3 角色并行,各自回写经验

## MVP 范围

- `~/.claude/org/` 骨架(INDEX + topics/ + agents/)
- `org` skill(SKILL.md)
- 跑通 1 个完整闭环:沉淀提案 → 确认 → 落盘 → 角色提案 → 确认 → spawn → 结果回写提案
