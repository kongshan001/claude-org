# 用例:DSH 插件安装审计方案

- **任务描述**:给一个声称是 bundle 型的 dsh 插件(如 dsh-restart)设计"安装前审计 + 安装 + 验证"方案,不实际执行
- **期望产出**:≤6 步方案,含安全核对、装法、验证法
- **验收点**:
  1. 安全核对包含 package.json 生命周期脚本(preinstall/install/postinstall)与 dsh 字段检查
  2. 装法为 bundle 三步:dependencies + dsh.profile.bundles 末尾追加 + profile 目录 pnpm install
  3. 提到受限 shell PATH 缺 /usr/bin 会导致 git ENOENT 失败(需补 PATH)
  4. 验证 = 整进程重启 + 探测插件路由(404 = 未加载)
  5. peer 依赖警告(react/cordis)是常态可忽略
- **历史得分**:—(baseline 首轮)
