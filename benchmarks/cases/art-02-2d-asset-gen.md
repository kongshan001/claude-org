# 用例:2D 游戏贴图资产生成（带锚点约束）

- **任务描述**:为 2.5D 俯视角场景生成"树"贴图资产（真实出图 + 本地交付，非仅方案）
- **期望产出**:PNG 透明贴图 3 张候选 + 校验报告 + 成本报告
- **验收点**:
  1. 交付 128×128 RGBA 透明背景 PNG（PIL 实测尺寸与 alpha）
  2. 锚点约束：树根/主体底部压到图片底边、水平居中（±2px，满足 y-sort 锚点规则）
  3. 报告含成本估算（0.22 元/张口径）与实测说明
  4. 不改动项目任何 .gd/.tscn；交付物仅贴图+报告
  5. SSO 失效时能降级（数据面直连 images/generations）并如实报告偏差
