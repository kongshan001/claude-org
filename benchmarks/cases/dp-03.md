# 用例:DSH 版本更新检查方案

- **任务描述**:设计"检测 @deepseek-ai/dsh 是否有新版本 + 一键更新"的方案要点
- **期望产出**:检查与更新方案要点(≤5 条)
- **验收点**:
  1. 最新版探测走 npm registry 直连(npmmirror → npmjs 双 registry 依次尝试),不受 GitHub API 限流影响
  2. 版本比较必须处理 prerelease(-rc.N 排序低于同号正式版)
  3. 状态接口返回 {local, latest, outdated} 三元组
  4. 更新执行后需提示重启进程生效
