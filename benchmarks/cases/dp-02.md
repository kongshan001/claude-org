# 用例:孤儿进程 dsh web 快速重启方案

- **任务描述**:dsh web 以孤儿进程运行(PPID=1,无看门狗),设计一个从 Web UI 触发的"快速重启"方案
- **期望产出**:重启机制设计(≤6 步),含进程身份、安全、失败兜底
- **验收点**:
  1. 识别孤儿进程特性(PPID=1)→ 必须自重生,无外部看门狗可依赖
  2. 自重生 = detached helper:SIGTERM 旧进程 → 轮询端口释放 → 同 argv 重拉
  3. spawn(detached:true, stdio:'ignore', unref()) 子进程在父进程退出后存活
  4. 重启 POST 需环回同源校验防跨站触发
  5. 新进程日志落盘(如 ~/.dsh/dsh-web-restart.*.log)供排障
- **历史得分**:—(baseline 首轮)
