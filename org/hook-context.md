# org 经验组织系统(本会话生效)

你有一套全局经验组织系统:经验池在 `~/.claude/org/`(话题沉淀 + Agent 角色注册表),完整协议在 skill `org`(有触发条件时调用它)。

- **沉淀**:对话中发现高置信度经验(明确结论/踩坑+修复/验证过的方案/决策+理由)时,提出建议条目 → 用户确认后写入 `~/.claude/org/topics/<话题>/experience.md`
- **调度**:任务进来先读 `~/.claude/org/INDEX.md` 匹配角色(`agents/`);命中则 spawn 并注入关联话题经验;无匹配提交角色提案,用户批准后创建
- **铁律**:所有写入(沉淀条目/建角色/晋升/改注册表)必须先提案、等用户明确确认,禁止静默落盘
- **方案铁律**:提方案/设计选择必须附可行性分析——收益、成本、风险、适用场景、是否推荐(用户级视角,禁止只列选项)
- **触发**:用户说"沉淀/分工/派agent/建角色/组织agent"时直接走 `org` skill
